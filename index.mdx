Superlog automates routine engineering work. It can triage alerts, answer support questions, and review performance and observability across your code and infrastructure. You choose the model and the agent harness, and you can run on your own API keys or your ChatGPT subscription.

Each automation has a trigger, instructions, repositories, and connectors. When the trigger fires, Superlog starts a fresh sandbox, checks out your repositories, and runs a coding agent on the task. The agent can read your tools, open pull requests, post to Slack, and create Linear issues.

## Bring your own inference

Every automation picks a model from OpenAI, Anthropic, Google Gemini, xAI, Mistral, or DeepSeek, and runs it in the Codex, Claude Agent SDK, or OpenCode harness. Add an API key or connect a ChatGPT subscription and runs use it. Without one, runs use the usage included in your plan. See [Models and harnesses](/automations/models).
