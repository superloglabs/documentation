Superlog scans your logs, finds the production issues your alerts miss, and posts each to Slack with its impact, root cause, and a suggested fix.

It reads telemetry from the tools you connect, such as OpenTelemetry, Sentry, Datadog, Grafana, AWS CloudWatch, Google Cloud, and PostHog. It investigates each new or growing error. When real users are affected, it posts a **finding** to the Slack channel you choose.

- It reads the GitHub repositories you select to find the cause. It never changes them.
- It skips problems already tracked in Linear, GitHub, Slack, or your Superlog alerts.
- Only posted findings count toward your plan.

## What a finding contains

| Part | What it says |
|---|---|
| Severity | SEV-1, SEV-2, or SEV-3 |
| Title and summary | What is broken, and who is affected |
| Impact | Affected users and requests, with counts |
| Root cause | Why it happens, from telemetry and your code |
| Suggested fix | A change to make, when Superlog has one |
| Evidence | The logs, traces, metrics, and code Superlog read |

Each finding has **Copy prompt**, which gives you a prompt to paste into your coding agent to fix it.

## Store telemetry in Superlog

Superlog can also store your logs, traces, and metrics for 30 days. Send them with OpenTelemetry, or connect Vercel, AWS CloudWatch, Google Cloud, Railway, or PostHog. Superlog finds new errors in this data as it arrives.

- [Instrument your app](/guides/instrument-your-app) with OpenTelemetry.

## Automations and tag mode

Workspaces can also run [automations](/automations/overview), which run a coding agent on a trigger and can open pull requests, and [tag mode](/tag-mode), which answers questions when someone mentions Superlog in Slack.

## Open source

Telemetry, automations, tag mode, and integrations are open source under the Apache License 2.0. The code is at [superloglabs/responder-oss](https://github.com/superloglabs/responder-oss). Findings run on the hosted service at [superlog.sh](https://superlog.sh). You can [run the open-source application yourself](/self-hosting/overview).
