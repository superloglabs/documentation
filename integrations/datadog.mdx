title: "Datadog"

---

Datadog gives agents your logs, metrics, monitors, and traces. Datadog alerts can start automations through a Slack channel.

## Connect Datadog

<Steps>
  <Step title="Create keys in Datadog">
    In Datadog, create an API key and an application key. Scope the application key to the data you want Superlog to read.
  </Step>
  <Step title="Add Datadog in Superlog">
    In **Integrations**, click **Add** on Datadog. Choose your Datadog site, paste the **API key** and **Application key**, and click **Connect Datadog**.
  </Step>
</Steps>

| Site | Domain |
|---|---|
| US1 | `app.datadoghq.com` |
| US3 | `us3.datadoghq.com` |
| US5 | `us5.datadoghq.com` |
| EU1 | `app.datadoghq.eu` |
| AP1 | `ap1.datadoghq.com` |
| AP2 | `ap2.datadoghq.com` |
| UK1 | `uk1.datadoghq.com` |

Choose the site your account uses. A wrong site means queries find no data.

## Let agents read Datadog

Add Datadog as a connector. The agent uses Datadog's MCP server for your site. Superlog passes its tools through without filtering, so the application key's scope is the limit on what the agent can do.

The **Reliability check**, **Review observability**, **Review performance**, and **Fix regressions** templates use Datadog. See [Templates](/automations/templates).

## Start automations from Datadog alerts

Send Datadog monitor notifications to a Slack channel. Then add a Slack **New message in channel** trigger on that channel. Recovery notifications are ignored. No Datadog webhook is needed.

## Tag mode

Tag mode can read Datadog when you turn it on for tag mode.
