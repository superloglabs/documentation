description: "Connect Slack to start automations from messages and mentions, let agents post and reply, and use tag mode."

Slack is where most teams talk to Superlog. Messages and mentions start automations, agents reply in threads and post to channels, and tag mode answers questions when someone mentions Superlog.

## Connect Slack

In **Integrations**, click **Add** on Slack and approve the app in your Slack workspace. To watch or post in a private channel, invite the Superlog app to that channel first.

## Start automations from Slack

Add a Slack trigger to an automation and pick the channels to watch:

- **New message in channel** for alert channels and request channels.
- **App mentioned** for requests addressed to Superlog.
- **Message posted or app mentioned** for both.

Tools that post alerts to Slack, such as Datadog, PostHog, Sentry, or AWS CloudWatch through Amazon Q Developer, can start runs this way. Recovery and resolved notifications from those tools are ignored. See [Triggers](/automations/triggers#slack).

When a Slack message starts a run, Superlog posts a progress card in the thread. People can reply in the thread to continue the run.

## Let agents use Slack

Add Slack as a connector to let the agent:

- Search for channels, and read channels and threads.
- Post messages and thread replies.
- Add and remove reactions.

Without the Slack connector, an agent started from Slack can read and reply only in its own thread. See [Connectors](/automations/connectors#slack).

Scheduled automations can also post each finished run to Slack channels. See [Notifications](/automations/runs#notifications).

## Tag mode

When tag mode is on, mentioning Superlog in any channel it can read starts a read-only investigation that replies in the thread. See [Tag mode](/tag-mode).

## Self-hosted setup

Self-hosted deployments need their own distributed Slack app.

Bot scopes:

```text
app_mentions:read
channels:history
channels:join
channels:read
chat:write
chat:write.public
groups:history
groups:read
reactions:write
```

User scope:

```text
search:read
```

| Setting | Value |
|---|---|
| OAuth redirect URL | `<public-url>/api/integrations/slack/callback` |
| Event subscriptions URL | `<public-url>/api/webhooks/slack` |
| Bot events | `app_mention`, `message.channels`, `message.groups` |
| Interactivity URL | `<public-url>/api/webhooks/slack/actions` |

Set `SLACK_CLIENT_ID`, `SLACK_CLIENT_SECRET`, and `SLACK_SIGNING_SECRET`. See [Environment variables](/self-hosting/environment).
