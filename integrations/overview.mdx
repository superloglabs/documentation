Integrations connect Superlog to the tools you already use. Connect them once per workspace, then use them as automation triggers, as automation connectors, or as context for tag mode.

## Connect an integration

Click **Integrations** in the sidebar. Find the tool under **Marketplace** and click **Add**. Depending on the tool, you approve access in the provider's sign-in page, paste an API key, or deploy a template in your cloud account. Connected tools move to **Connected integrations**, where **Manage** opens their settings.

You can also connect a tool from the automation editor. Click **Connect** on a trigger or in the connector picker. Your draft stays open while you approve access.

Credentials are encrypted before storage and scoped to your workspace.

## How access is limited

- Most built-in integrations expose only read-only tools, plus the write actions listed above.
- Datadog and custom MCP servers pass their tools through without filtering. Supabase allows writes only if you choose **Full database SQL access**. Scope the credentials you give them.
- Provider credentials stay outside the agent's sandbox. Superlog calls the provider on the agent's behalf.
- If an integration cannot be reached during a run, the agent gets a reconnect tool with the error and decides whether to retry. The run continues.

See [Security](/security) for more detail.
